3. CONVERSION TRACKING (required before spending)
---

In GA4 Admin → Events:
  • quote_request  → Mark as key event
  • purchase       → Mark as key event
  • generate_lead  → Mark as key event (if used)

In Google Ads → Goals → Conversions:
  • Import quote_request from GA4 (primary for Campaign A)
  • Import purchase from GA4 (primary for Campaign B)
  • Bidding: Start with Maximize conversions (no target CPA for month 1)
  • After 15+ quote conversions: switch Campaign A to Target CPA (~$25–40 AUD per quote — adjust from data)

6. WEEK-BY-WEEK CHECKLIST
---

Week 1 — Launch
  [ ] Import google-ads-keywords-perth.csv (Google Ads → Tools → Bulk upload)
  [ ] Create 3 campaigns with budgets above
  [ ] Enable only 4 ad groups on Campaign A, 3 on Campaign B, 1 on Campaign C
  [ ] Add negative keyword list
  [ ] Link GA4 ↔ Google Ads
  [ ] Verify quote_request fires when you submit a test quote on /quote

Week 2 — Optimise
  [ ] Search terms report: add negatives for irrelevant queries
  [ ] Pause keywords with $30+ spend and zero conversions
  [ ] Enable 1 paused ad group if CPA is acceptable

Week 3 — Scale or cut
  [ ] If quote CPA < $35: move $1/day from Brand → Bulk Quote
  [ ] If quote CPA > $60: narrow to Brand + Perth bulk quote ad groups only
  [ ] Enable Industries ad group if bulk is performing

Week 4 — Review
  [ ] Total spend ≈ $300?
  [ ] Quotes received: target 5–12 (varies by season)
  [ ] Orders: even 2–5 online orders = acceptable for month 1
  [ ] Decision: keep $300, increase to $500, or pause Retail and focus Bulk only
